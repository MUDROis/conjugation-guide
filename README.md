# Conjugation Guide — English · Français · Español

Статический сайт-словарь спряжений глаголов на трёх языках. Работает как словарь: вводите глагол — и видите полные таблицы спряжений по временам, с примерами и озвучкой каждой формы.

## Возможности

- **Поиск** по инфинитивам, по любой форме глагола (`went`, `allons`, `tuviste`) и по русским переводам (`быть` → be / être / ser)
- **Словарь:** 185 английских, 178 французских и 198 испанских глаголов с сетками времён уровня B2
- **Таблицы спряжений** для каждого времени: лица, местоимения, подсветка неправильных форм, грамматические заметки
- **Примеры** к каждому времени с переводом на английский и русский
- **TTS-озвучка** любой формы и примера (Web Speech API)
- **Навигация:** липкая панель времён со скроллспаем, hash-роутинг (`#/en/go`), перекрёстные ссылки между языками
- **Дизайн:** современный, минималистичный, светлый, адаптивный

## Структура

```
index.html          — приложение (интерфейс + движок + поиск)
data/english.js     — английские глаголы (185)
data/french.js      — французские глаголы (178)
data/spanish.js     — испанские глаголы (198)
_build.js           — пересборка index.html из исходных частей
_test.js            — рантайм-проверки (загрузка, поиск, рендер)
```

## Запуск

Откройте `index.html` в браузере (работает и через `file://`, и на любом статическом хостинге).

## Проверки

- `node --check` — синтаксис всех JS-частей
- `node _test.js` — полный рантайм-тест: загрузка данных, ключевые формы, поиск, целостность таблиц
